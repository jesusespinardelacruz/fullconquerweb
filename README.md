# Conquer Blocks | Proyecto Web

### Desarrollo Frontend · HTML5 · SCSS · Responsive Design

Proyecto de desarrollo web inspirado en la academia de formación tecnológica **Conquer Blocks**, realizado como práctica de maquetación y diseño frontend en base al Ejercicio 5 del módulo CSS.

El objetivo es construir una interfaz moderna, intuitiva y adaptable a diferentes dispositivos, aplicando buenas prácticas de desarrollo web, organización del código y diseño responsive.

## Sobre el proyecto

La web presenta una propuesta visual para una academia de formación tecnológica, organizando sus contenidos de manera clara y accesible.

Entre las secciones trabajadas se encuentran:

- **Inicio:** presentación de la academia y su propuesta formativa.
- **Formaciones:** información sobre programas y especialidades tecnológicas.
- **Formadores:** presentación del equipo docente.
- **Blog:** espacio para contenidos y novedades.
- **Contacto:** formulario y diferentes vías de comunicación.
- **Acceso de usuarios:** elementos visuales para registro e inicio de sesión.

## Características técnicas

- Estructura semántica mediante HTML5.
- Estilos desarrollados con SCSS y compilados a CSS.
- Metodología Mobile First.
- Diseño adaptable mediante Flexbox, CSS Grid y Media Queries.
- Organización modular de estilos.
- Uso de variables, anidamiento y mixins de Sass.
- Componentes visuales reutilizables.
- Uso de Git y GitHub para el control de versiones.

## Objetivos de aprendizaje

Este proyecto permite poner en práctica conocimientos fundamentales de desarrollo frontend:

1. Estructurar correctamente una página web mediante HTML semántico.
2. Aplicar estilos escalables utilizando Sass.
3. Construir interfaces responsive.
4. Trabajar con sistemas de distribución mediante Flexbox y Grid.
5. Mejorar la organización y mantenibilidad del código.
6. Consolidar el flujo de trabajo con Git y GitHub.

## Ejecución del proyecto

Para visualizar el proyecto localmente:

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir `index.html` en el navegador o utilizar la extensión Live Server.
4. Para modificar los estilos SCSS, compilar los archivos Sass a CSS.
